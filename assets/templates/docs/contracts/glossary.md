# 术语表（唯一命名源）

一个概念只允许一个名字。代码、文档、报错文案、日志字段、界面文案必须一致
（`CONSTITUTION.md` 第二条）。

规则：

- 新增概念先来这里登记，再写代码。
- 同义词是 bug：发现两个名字指同一个东西，当场合并并全局替换，不要"两个都能用"。
- 一个名字只指一个东西：不要让 `order` 在不同模块里分别表示"订单"和"排序"。
- 命名风格统一：表名用单数还是复数、接口路径用连字符还是下划线、布尔字段是否 `is_` 前缀 —— 定一次，全局照办。

| 概念（中文） | 代码标识符 | 类型 / 字段名 | 说明与边界 | 禁止的说法 |
|---|---|---|---|---|
| 订单 | `order` | 表 `orders` / 字段 `order_id` | 用户提交的购买请求；不包含支付状态 | `bill`、`purchase`、`trade` |

## 命名风格约定（定一次，别改）

- 目录 / 文件：`kebab-case` | `snake_case`（选一个）
- 类 / 类型：`PascalCase`
- 函数 / 变量：`camelCase` | `snake_case`（选一个）
- 常量：`SCREAMING_SNAKE_CASE`
- 数据库表：单数 | 复数（选一个）
- HTTP 路径：`/kebab-case`
- 布尔：`is_` / `has_` 前缀
- 时间字段：统一 `_at` 后缀且带时区；统一单位为毫秒 | 秒（选一个）
