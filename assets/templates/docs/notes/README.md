# 调研笔记（recon 模式的唯一可写目录）

任务目标尚不明确时，在 `TASK.md` 声明 `mode: recon`，此时 Agent：

- 允许：读源码、跑只读命令、在本目录写笔记
- 禁止：修改任何生产代码与测试

笔记要求：

- 一个调研一个问题一个文件，命名 `<日期>-<主题>.md`
- 只写事实与判断（"现在的数据流是 A → B"、"这里有个隐藏前提"），不写方案文档的套话
- 结尾必须给出「建议方案 + 建议范围（哪些文件该进白名单）」，供人类确认后转 `mode: execute`

笔记不会被 `scope-check` 默认放行，需要写的话把 `docs/notes/` 加进 `TASK.md` 的 `SCOPE:MODIFY`。
