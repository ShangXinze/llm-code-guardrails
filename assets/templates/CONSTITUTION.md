# CONSTITUTION.md — {{PROJECT}} 项目宪法

本文件是项目的**全局不变量**：所有模块、所有任务都必须遵守。与个案判断冲突时，以本文件为准。

- 只有人类可以修改本文件。Agent 只能提「宪法修正案」（写在 `TASK.md` 的「规则变更请求」里）。
- 每条都必须可判定。写不出判定方式的，不要写进来（放进 `AGENTS.md` 的建议区）。
- 新增模块、新增任务前，先读一遍本文件；复述时说明哪几条对本任务生效。

---

## 第一条 可读性优先于聪明

代码以「新人 10 分钟能读懂」为标准，不以「行数少」「写法高级」为标准。

- 控制流线性、早返回、卫语句；嵌套 ≤ 3 层（由 lint 强制，见 `references/readability.md` 的配置配方）。
- 命名表达意图：动词 + 名词。禁止 `data` / `info` / `handle` / `process` / `manager` / `util` / `temp` 这类空词
  （由 `scripts/consistency-audit.mjs` 检查）。
- 不写单行转发的包装层、只有一个实现的接口、只被调用一次的工具函数。
- 重复三次再抽象；抽象出来的东西必须让调用处更好读，而不是更短。
- 注释只解释 why、约束、坑；不解释 what。`TODO` 必须带任务 ID。

## 第二条 一致性优先于局部最优

- 同类问题只有一种写法：错误处理、日志、配置读取、数据访问的套路统一放在 `docs/contracts/`，新代码照抄。
- 新模块先找最像的既有模块抄结构，不要自创目录与命名风格。
- 同一个概念只允许一个名字：代码、文档、报错文案、日志字段必须一致（术语表 `docs/contracts/glossary.md`）。
- 不引入并行实现：已有能力要复用，不允许「我这边也写一个更简单的版本」。

## 第三条 依赖方向不可逆

- 依赖方向：`entry → modules → shared`；`modules → infra`；禁止反向依赖与循环依赖。
- 跨模块调用必须走对方公开入口，不许深引内部文件（由 `consistency-audit` 检查）。
- 模块间依赖必须在 `ROADMAP.md` 的模块注册表里声明；没声明就不许引用。
- 新增外部依赖需要人类批准。

## 第四条 证据高于声明

- 任何「完成 / 修好了」，必须附命令与输出。不接受「看起来没问题」「应该可以」。
- 每条验收标准都要能对应一条命令或一个明确的人工判定。
- 修 bug 必须先有能复现失败的测试；没有复现就不要改代码（见 `references/verification.md`）。
- 验证日志落盘到 `var/verify-<时间戳>.log`，对话里只给结论与路径。

## 第五条 不偏移

- 一次只做一个任务卡（`TASK.md` 指向的那个），做完、归档、再取下一个。
- 范围以 `TASK.md` 的 `SCOPE:` 哨兵块为准；越界先停、先申请，不自行扩权。
- 不做「顺手」：顺手重构、顺手修 bug、顺手升级、顺手格式化，一律不做。发现问题记进「未决问题」。
- 计划外发现必须在 `TASK.md` 留痕，不许静默处理。

## 第六条 契约先行

- 跨模块接口、数据模型、错误码、事件，先写进 `docs/contracts/` 再实现。
- 契约变更必须在**同一个任务内**同步所有使用方，不允许「先改一边，另一边下个任务再说」。
- 对外接口变更必须同步模块 `README.md`（由 `consistency-audit` 检查文档与代码是否一致）。

## 第七条 完成定义（Definition of Done）

一个任务只有同时满足以下全部，才允许把状态改成 `done`：

1. 验收标准逐条有对应命令与通过输出（红 → 绿的过程有记录）；
2. `scripts/verify.* --full` 全绿，`consistency-audit` 通过；
3. 新增/修改的公开接口已同步到模块 `README.md` 与 `docs/contracts/`；
4. 新增分支有测试覆盖，至少包含一条边界或失败路径；
5. 两阶段评审（先对规格、再对代码质量）已完成，见 `.agents/checklists/task-review.md`；
6. 任务卡已归档到 `{{TASKS_REL}}/`，`ROADMAP.md` 状态已更新；
7. 没有未申报的测试改动、没有未登记的 TODO、没有残留占位符。

一个模块只有它名下的任务全部 `done`、且模块文档核验日期已更新，才允许标 `done`。
全部模块 `done` 后，执行 `ROADMAP.md` 的「里程碑验收」清单，才算项目整体完成。
