## 何时必须新增 ADR

- 新增外部依赖或外部服务
- 新增模块 / 拆分或合并模块
- 修改公共接口或数据模型
- 改变依赖方向
- 引入新的运行、构建或部署方式

只影响单个模块内部实现的决策，写在该模块 README 的「已知约束 / 坑」里即可，不必开 ADR。

命名：`ADR-<四位序号>-<短横线标题>.md`，序号只增不复用；废弃的 ADR 保留原文，把状态改成「已废弃」并写明被谁取代。
